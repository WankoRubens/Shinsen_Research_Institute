# Local Battle Report OCR Models

The PP-OCRv5 mobile detection and recognition ONNX archives are distributed
with this site. Inference runs inside the browser's dedicated worker. No image
is uploaded to a recognition service.

Source: PaddlePaddle/PaddleOCR (Apache-2.0), official inference assets used by
`@paddleocr/paddleocr-js` 0.4.2:

- https://paddle-model-ecology.bj.bcebos.com/paddlex/official_inference_model/paddle3.0.0/PP-OCRv5_mobile_det_onnx_infer.tar
- https://paddle-model-ecology.bj.bcebos.com/paddlex/official_inference_model/paddle3.0.0/PP-OCRv5_mobile_rec_onnx_infer.tar

Runtime reference: https://github.com/PaddlePaddle/PaddleOCR/tree/main/paddleocr-js
